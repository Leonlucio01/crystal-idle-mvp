# Unity Combat Layout Fix

Copia `Assets` dentro de tu proyecto Unity.

Incluye:
- Assets/Scripts/UI/GameUI.cs
- Assets/Scripts/UI/GameSceneLayout.cs

Luego:
1. Abre GameScene.
2. Sal de Play Mode.
3. Selecciona Canvas/GamePanel.
4. En GameSceneLayout ejecuta Apply Layout.
5. Guarda con Ctrl+S.
6. Prueba desde LoginScene.
