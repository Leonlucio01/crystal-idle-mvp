# Assets References

## Visual Direction

El juego tomará inspiración visual de MMORPGs fantasy como MU Online y Legend of Angel:

- Armaduras brillantes
- Armas grandes
- Alas
- Cristales mágicos
- Monstruos demoníacos
- Auras y efectos de poder
- Bosses grandes
- Progresión visual clara

Para el MVP se usará un estilo stylized / low-poly para reducir complejidad.

## Legal Rule

No usar assets oficiales de MU Online, Legend of Angel ni otros juegos propietarios.

No usar:

- Modelos rippeados
- Mapas extraídos
- Logos oficiales
- Iconos oficiales
- Sonidos oficiales
- Texturas oficiales

Usar solo:

- Assets CC0
- Assets MIT/permisivos
- Assets comprados
- Assets propios
